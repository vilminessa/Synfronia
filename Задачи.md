# Задачи

Текущая работа: ветка `dev-ui` - «магнитные» подсказки: карточка «Подсказки»
в разделе «Интерфейс» с двумя силами 0..100. «Притяжение к курсору»
(`tip_pull`, дефолт 50) - множитель к инерции следования; «Отталкивание от
элемента» (`tip_repel`, дефолт 100) - зазор до элемента и жёсткость
выталкивания подсказки из его рамки. Дефолты повторяют прежнее поведение;
значения уходят в `TIP_FORCE` (common.js) сразу при правке поля/слайдера и
с каждым `poll()`. Зонд проверяет наличие и переводы полей, сохранение,
мгновенное применение и само поведение (перекрытие при repel 0/100, скорость
схождения при pull 0/100).

Также в стеке веток: `dev-core` - установка ffmpeg переживает вспышки
HTTP 503 на gyan.dev: `download_ffmpeg()` получил повторы с бэкоффом
(4 попытки на источник, паузы 2/4/8 с) и запасное зеркало
`github.com/BtbN/FFmpeg-Builds` (тот же `ffmpeg.exe`/`ffprobe.exe` внутри),
лог сообщает источник и номер попытки; живой тест установил ffmpeg 9.0.2
в `%LOCALAPPDATA%\Synfronia\bin`.

Ранее: `d922889` - тумблер выгрузки видим (SVG-namespace), подсказки полей,
скрытое пустое пояснение; релиз **v1.2.6.4** на forgejo и GitHub отмечен
коммитом `da77d84` (ветки `main`/`master`).

## Решения, принятые с пользователем

1. Настройки - карточка по центру главного окна, фон под ней размыт
   (не отдельное окно, не правая панель).
2. Режимы выгрузки FTP: «Пакет» / «Пофайлово», пояснение - в подсказке
   при наведении.
3. Базовые темы докачиваются **офлайн**: пересоздаются из встроенных
   данных `themes.py`, без сети.
4. Новый компонент подсказок применяется везде вместо нативного `title`.
5. Кнопка без SVG-иконки остаётся с текстом; где иконка есть - только
   иконка с анимацией наведения и нажатия, значение в подсказке.
6. Сторонние библиотеки не используются, лицензии/атрибуция не меняются.

- 2026-09-28 (пакет 3, итог): причина «невидимого» тумблера найдена живой

  UI должны мерять namespace и геометрию, а не только computed-стили.
