## Решения, принятые с пользователем

1. Настройки - карточка по центру главного окна, фон под ней размыт
   (не отдельное окно, не правая панель).
2. Режимы выгрузки FTP: «Пакет» / «Пофайлово», пояснение - в подсказке
   при наведении.
3. Базовые темы докачиваются **офлайн**: пересоздаются из встроенных
   данных `themes.py`, без сети.
4. Новый компонент подсказок применяется везде вместо нативного `title`.
5. Кнопка без SVG-иконки остаётся с текстом; где иконка есть - только
   иконка с анимацией наведения и нажатия, значение в подсказке.
6. Сторонние библиотеки не используются, лицензии/атрибуция не меняются.
