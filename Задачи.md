# Задачи

Текущая работа: третий пакет правок (по замечаниям) - пиксельный
переключатель выгрузки на FTP стал видимым: он не использовал переменные
темы (`--panel`/`--line`/`--text-dim` в темах не заданы, поэтому заливка
падала в чёрное и грань сливалась с карточкой), теперь палитра из
существующих переменных (`--surface`/`--widget`/`--text`/`--accent`/`--bg`),
размер 40x20, дорожка-граница, акцент по наведению. Подсказка схемы
перекодировки переехала с подписи на само поле, а пояснение под
перекодировщиком скрывается, когда в нём нет текста.
Ветка `dev-ui`, предыдущий коммит - `a5e6cb8`.

## Решения, принятые с пользователем

1. Настройки - карточка по центру главного окна, фон под ней размыт
   (не отдельное окно, не правая панель).
2. Режимы выгрузки FTP: «Пакет» / «Пофайлово», пояснение - в подсказке
   при наведении.
3. Базовые темы докачиваются **офлайн**: пересоздаются из встроенных
   данных `themes.py`, без сети.
4. Новый компонент подсказок применяется везде вместо нативного `title`.
5. Кнопка без SVG-иконки остаётся с текстом; где иконка есть - только
   иконка с анимацией наведения и нажатия, значение в подсказке.
6. Сторонние библиотеки не используются, лицензии/атрибуция не меняются.

- 2026-09-28: висевшая подсказка - `pointerout` не приходит, когда
  карточка перерисовывает элемент под курсором; теперь живость по
  `pointermove` и явный `hideTip()` при перерисовке/закрытии.
- Нить и инерцию не потребовали сторонних библиотек (Floating UI/Popper

  SVG/DOM, `THIRD_PARTY_NOTICES.md` не меняется.
- 2026-09-28 (пакет 2): подсказки остались только там, где без них не
  понять (иконки, режимы, параметры с галкой). Текстовым кнопкам,
  разделам и «Скачать» подсказка не нужна: смысл уже в подписи, у кнопки
  «Скачать» состояние отдаёт `aria-label`.
- Пиксельный переключатель - `<label>` с инлайн-SVG и спрятанным нативным
  checkbox внутри: Toggle'инг работает нативно (клик по SVG), стилизуется
  как майнкрафтовский тумблер (грани без скруглений, `steps(3)`).
- Uiverse.io в среде недоступен (403), поэтому «майнкрафтовский» тумблер
  собран вручную по описанию - CSS + инлайн SVG, без сторонних библиотек.
- «—» (U+2014) убран из значений i18n, README, Задачи.md и строк лога;
  остался только в комментариях кода (scope: пользовательские тексты).
- 2026-09-28 (пакет 3): невидимый тумблер - CSS ссылался на переменные,
  которых ни одна тема не задаёт (`--panel`/`--line`/`--text-dim`):
  неопределённые `var()` дают `fill` чёрный и `stroke: none`, тумблер
  сливался с тёмной карточкой. Палитра переведена на реальные переменные.
- Тумблер - `div` с ручным кликом: `<label>` не годится (клик по SVG его
  не включает), поэтому `onPxClick` сам переключает скрытый checkbox и
  рассылает `change`, а `aria-label`/подсказка висят на `div`.
- `transform` ползунка с `transition: .09s steps(3)` в момент переключения
  ещё `matrix(...,0,0)`: браузер возвращает стартовое значение, поэтому
  зонд читает положение после таймаута 260 мс, а не синхронно.
